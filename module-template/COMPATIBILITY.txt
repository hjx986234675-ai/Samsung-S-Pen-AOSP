The adaptation calls AOSP public/internal interfaces, Root commands, Linux input and Samsung sec_epen/EFS hardware interfaces. The adapter source audit found no EvoX/Lineage API dependency; the new media and tip-input adapters use Android SDK interfaces. org.evox.spen is a local namespace.
AOSP hidden APIs are version-sensitive. Tested SM-T970/gts7xlwifi Android17 API37 only; Android15/16 and other devices have not been verified.
Three Samsung packages are mounted as regular system apps, not platform-signed privileged apps. Original Samsung UI and user mappings are retained. KernelSU Root authorizations remain necessary. Only Air Command needs an application Root grant. Capture and magnifier use its fixed signed hardware operations; the magnification accessibility service is inside Air Command.
AOSP Settings EXTRA_SETTINGS/IA_SETTINGS metadata points directly to original Samsung S Pen settings. No Settings.apk/framework.jar replacement, no ROM-partition write and no permissive SELinux rule.
Uses a narrow early OverlayFS mount of /system/app when no mounting backend provides our app dirs. Requires kernel OverlayFS, tested present on this device. Other installed modules are not mounted by this module. If startup.log lacks SYSTEM in pkgFlags, mounting has not completed and Settings may not show the injected tile.
Disable this module and reboot to remove system mounts. Existing data-installed packages and mappings stay intact. No rollback APK is distributed by this source-only repository.
